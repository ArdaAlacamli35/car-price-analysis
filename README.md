# Car Price Analysis and Prediction 🚗📊

## 📌 Project Overview
This project analyzes the factors affecting second-hand vehicle prices using Python. By examining features such as mileage, year, brand, and transmission types, we uncover key insights into the automotive market pricing dynamics.

## 📁 Dataset
Due to GitHub's file size limitations (>25 MB), the complete dataset (`car_prices.csv`) cannot be hosted directly in this repository. 
* You can download and access the original dataset via Google Drive: **[Download car_prices.csv Dataset Here](https://drive.google.com/file/d/1aVu17u_T_hIAk2yQCP7UTDhcXO4iCcf2/view?usp=sharing)**

## 🛠 Technologies Used
* **Python**
* **Pandas & NumPy** (Data Manipulation)
* **Matplotlib & Seaborn** (Data Visualization)
* **Google Colab** (Development Environment)

## 🚀 How to Run the Code
1. Open the `BVA_Bitirme_Projesi.ipynb` file in Google Colab or Jupyter Notebook.
2. Download the dataset from the Google Drive link provided above.
3. Update the file path in the code to point to your dataset location and run the cells sequentially.
